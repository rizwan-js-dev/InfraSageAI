# Environment variables

Single repo-root `.env` (gitignored), read by `docker compose` and by the API (`apps/api/src/config/env.ts`,
parsed once with Zod at startup; the API exits with a list of invalid variable **names** — never values).
Empty values are treated as unset. `.env.example` contains placeholders only.

The web app never reads this file at runtime: `apps/web/vite.config.ts` reads it on the Node side only to
learn ports; nothing is passed to the client bundle (enforced by an ESLint rule on `apps/web/src`).

| Variable                                                                                                          | Default                            | Read by                      | Phase                   | Notes                                          |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ---------------------------- | ----------------------- | ---------------------------------------------- |
| `NODE_ENV`                                                                                                        | `development`                      | api                          | 1                       | `development \| test \| production`            |
| `API_HOST`                                                                                                        | `127.0.0.1`                        | api, vite proxy              | 1                       | Must be loopback outside production (ADR-0003) |
| `API_PORT`                                                                                                        | `4000`                             | api, vite proxy              | 1                       |                                                |
| `WEB_ORIGIN`                                                                                                      | `http://localhost:5173`            | api (CORS), vite (host/port) | 1                       |                                                |
| `LOCAL_DEV_USER`                                                                                                  | `local-developer`                  | api                          | 1                       | Identity of every request (ADR-0003)           |
| `MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_DATABASE`                                                                    | `127.0.0.1` / `3306` / `infrasage` | api, compose                 | 1                       |                                                |
| `MYSQL_ROOT_PASSWORD`                                                                                             | —                                  | compose only                 | 1                       | Never read by application code                 |
| `MYSQL_APP_USER` / `MYSQL_APP_PASSWORD`                                                                           | `infrasage_app` / **required**     | api, compose                 | 1                       | SELECT/INSERT/UPDATE/DELETE, no DDL            |
| `MYSQL_RO_USER` / `MYSQL_RO_PASSWORD`                                                                             | `infrasage_ro`                     | compose; MCP server          | 1 (user), 3 (use)       | Table-level SELECT granted in Phase 2          |
| `MYSQL_MIGRATOR_USER` / `MYSQL_MIGRATOR_PASSWORD`                                                                 | `infrasage_migrator`               | compose; `db:migrate`        | 1 (user), 2 (use)       | DDL on app schema                              |
| `REDIS_PORT`                                                                                                      | `6379`                             | compose                      | 1                       | Host port; keep `REDIS_URL` in sync            |
| `REDIS_URL`                                                                                                       | `redis://127.0.0.1:6379`           | api                          | 1                       |                                                |
| `PROVIDER_MODE`                                                                                                   | `mock`                             | api                          | 1                       | Only `mock` accepted until Phase 8             |
| `LLM_MODE`                                                                                                        | `mock`                             | api                          | 1                       | `openai` requires key and model (fails fast)   |
| `OPENAI_API_KEY`                                                                                                  | —                                  | api                          | 1 (validated), 5 (used) | Server-side only; never `VITE_`                |

| `HEALTH_CHECK_TIMEOUT_MS`                                                                                         | `1500`                             | api                          | 1                       | Per-dependency probe timeout (max 10000)       |
| `RATE_LIMIT_WINDOW_MS` / `RATE_LIMIT_MAX` / `RATE_LIMIT_MUTATING_MAX`                                             | `60000` / `300` / `30`             | api                          | 1                       | Per client; mutating = non-GET/HEAD/OPTIONS    |
| `LOG_LEVEL`                                                                                                       | `info`                             | api                          | 1                       | pino level                                     |
| `LOG_PROMPTS`                                                                                                     | `false`                            | api                          | 1 (validated), 5 (used) | Only allowed when `NODE_ENV=development`       |
| `OPENAI_TIMEOUT_MS`, `OPENAI_MAX_RETRIES`, `OPENAI_MAX_INPUT_TOKENS`, `OPENAI_MAX_OUTPUT_TOKENS`                  | see `.env.example`                 | api                          | 5                       | Not parsed yet                                 |
| `MCP_SERVER_ENTRY`, `MCP_TOOL_TIMEOUT_MS`, `MCP_MAX_CONCURRENT_CALLS`, `MCP_MAX_RANGE_MINUTES`, `MCP_MAX_SAMPLES` | see `.env.example`                 | api, MCP server              | 3                       | Not parsed yet                                 |
